# Master prompt: адаптация учебных материалов под российского школьника

## Цель
Собрать, адаптировать и проверить учебные материалы так, чтобы:
- структура оригинала сохранилась;
- математика не изменилась;
- контекст стал естественным для российского школьника;
- JSON/код были валидны;
- качество было высоким, а перерасход — минимальным.

## Жёсткие правила
1. Не ломай структуру файлов и ключей.
2. Не делай два агента на одни и те же файлы.
3. Не меняй учебную цель задачи.
4. Не используй китайские реалии там, где нужен русский контекст.
5. Любой результат проходит QA до финального принятия.

## Маршрут работ
### 1) PDF-анализ
- Извлечь текст/OCR.
- Собрать карту: глава, класс, тема, страницы, тип задания, картинки.
- На выходе: `source_registry.json`.

### 2) Canonical template
- Зафиксировать эталонный JSON/структуру.
- Записать обязательные поля и запреты на изменение формата.

### 3) Curriculum
- Сохранить логику темы и усложнения.
- Локализовать контекст под РФ.
- Не смешивать файловые семьи между агентами.

### 4) Lessons
- Генерировать уроки только из утверждённого curriculum.
- Держать стиль единым.
- Не трогать чужие band/классы.

### 5) QA
- Проверить JSON, схему, стиль, возрастную уместность, уникальность задач.
- Отдельно: schema QA и content QA.

### 6) Fix
- Чинить только конкретные ошибки QA.
- Не переписывать всё заново.

### 7) Final integration
- Свести PDF → curriculum → lessons → QA.
- Дать короткий статус: готово / нужен фикс.

## Распределение по моделям
- **gpt-5.5** — финальный архитектор/интегратор: спорные решения, финальная сборка, приоритеты.
- **gpt-5.4** — QA-лид: проверка качества, полноты, логики, соответствия канону.
- **gpt-5.4 mini** — дешёвый анализатор: быстрый разбор PDF/страниц, черновые сводки, поиск дублей.
- **gpt-5.3 codex** — fixer: точечные правки JSON/кода, устранение ошибок схемы.
- **gpt-5.2 codex** — основной writer/generator: curriculum и lesson JSON по утверждённой структуре.
- **gpt-5.1 codex max** — сложные случаи: неоднозначные страницы, трудные решения, тяжёлые исправления.
- **gpt-5.1 codex mini** — мелкие повторяющиеся преобразования, нормализация, batch-правки.

## Когда что запускать
### PDF-анализ
- Сначала `gpt-5.4 mini`.
- Если есть OCR/спорные страницы — `gpt-5.1 codex max`.

### Curriculum
- Основной writer: `gpt-5.2 codex`.

### Lessons
- Основной generator: `gpt-5.2 codex`.

### QA
- Основной reviewer: `gpt-5.4`.

### Fix
- Основной fixer: `gpt-5.3 codex`.

### Финальная сборка
- `gpt-5.5`.

## Чеклист качества
### Структура
- [ ] JSON валиден
- [ ] Все обязательные ключи на месте
- [ ] Формат совпадает с canonical template
- [ ] Ничего не потеряно при правке

### Содержание
- [ ] Учебная цель сохранена
- [ ] Контекст естественный для РФ
- [ ] Нет китайских имён/валюты/праздников без необходимости
- [ ] Возрастной уровень соответствует классу
- [ ] Задачи уникальны внутри family/grade

### Curriculum / lessons
- [ ] Порядок тем не сломан
- [ ] Сложность идёт по нарастающей
- [ ] CPA/пошаговая подача сохранена, если нужна
- [ ] Уроки согласованы с curriculum

### QA / fix loop
- [ ] Ошибки QA конкретны и воспроизводимы
- [ ] Fix касается только найденных проблем
- [ ] Повторный QA проходит после правки

### Финал
- [ ] PDF → curriculum → lessons → QA согласованы
- [ ] Нет пересечений между агентами
- [ ] Результат можно коммитить/отдавать

## Короткий operational rule
**Сначала дешёвый анализ, потом основной writer, потом QA, потом точечный fix, и только затем финальная сборка.**
