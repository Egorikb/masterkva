## Исправления и итоговая приёмка

Sol независимо проверил реализацию и исправил два существенных дефекта в `plugins_api.py`:

- Вход в curricular затирал текущие задание/навык прежнего занятия, а явный возврат в `kungfu/homework` не работал. Теперь исходный контекст сохраняется и восстанавливается; сообщение переключения не засчитывается как ответ.
- Сериализатор копировал сохранённые practice/feedback целиком; лишние поля могли попасть в ответ ребёнку. Теперь выдаются только разрешённые поля; визуальный ответ использует ту же очищенную структуру. Текстовая пауза и возврат также используют детский curricular-ответ.

Для rubric исправлено обещание «ответ сохранён»: текущая реализация сообщает о необходимости проверки взрослым, автоматической оценки и очереди на проверку не создаёт.

Добавлены регрессии для этих дефектов, запрета остальных **77 уроков**, изменения HTTP-оценки при изменении эталона в тестовой копии JSON, точного совпадения topic+family и сохранения item_family в диагностике. Последовательность ordered и запрет mastery для rubric проверены синтетическими прямыми вызовами обработчиков; настоящий HTTP-пилот остаётся одним exact-уроком.

## Передача API для U1

Endpoint: `POST /api/v1/plugins/panda/chat`.

Начало урока:

```json
{
  "user_id": "synthetic-b1-child",
  "message": "",
  "mode": "curricular",
  "action": "start",
  "lesson_id": "g1-t12-l01",
  "content_version": "2.0"
}
```

Ответ ребёнка отправляется с тем же `user_id`, `action=answer`, текстом ответа в `message`. Подсказка — `action=hint`, а переход между частями — `action=advance`; номер части и завершение определяет сервер. Реальный разрешённый урок состоит из одной части, поэтому верный ответ завершает урок без перехода и без повышения mastery.

В запросах пилота сохранять `mode=curricular` либо не передавать mode после start. Явное `mode=kungfu` или `mode=homework` возвращает сохранённое прежнее занятие; текст этого запроса не оценивается. Сообщение «стоп» приостанавливает урок, следующая реплика возвращает текущую часть без оценки. Явные действия pause/rephrase и защита от повторного запроса относятся к B2.

Frontend-контракт: [panda.ts](../../frontend/contracts/panda.ts). `current_practice` содержит вопрос, идентификатор урока/версии и номер части; поле `answer` не требуется. Режим и состояние curricular уже типизированы, но текущий экран чата не предоставляет отдельный вход в этот пилот. Новый экран, кнопки и проверка удобства ребёнком — U1.
