# Приёмка U1a — первый текстовый B1-урок

Дата: 23.09.2026. Ветка: `codex/b1-curricular-runtime-2026-09-11`, реализация U1a `8e590c4`. Основа: принятые B1, B2a и B2b. В проверке использовался только синтетический локальный профиль; реальные состояния детей не читались и не включаются в Git.

## Результат

- Экран занятия явно предлагает «Учебный урок», затем единственный разрешённый блок: «Математика · 1 класс → Состав числа до 10» (`g1-t12-l01` v2.0). Другие 77 уроков не показаны и не могут быть выбраны из UI.
- После запуска ребёнок видит один текущий вопрос, поле ответа и крупные кнопки «Подсказка», «Объясни иначе», «Пауза». Для паузы доступно «Продолжить», для перехода сервер сам открывает кнопку следующей части, а по завершении блокирует ввод.
- Клиент всегда передаёт `mode=curricular`, `lesson_id`, `content_version`, новый `request_id` и полученные `session_id`/`part_revision`. Он повторяет прежний ID только после ошибки доставки; правильный ответ, счётчик попыток, mastery и следующий шаг не вычисляет.
- Недоступный backend выводит понятную ошибку и кнопку безопасного повтора. Возврат вызывает сохранённый серверный legacy-переход и отображает его ответ один раз.

В браузере с синтетическим профилем пройдены: выбор единственного урока → старт → `12` → подсказка → `13` → завершение без следующего урока; пауза → продолжение; возврат к прежнему занятию. ## Сценарий владельца для H0

1. В отдельном тестовом окружении запустить `cd backend && python3 -m uvicorn main:app --host 127.0.0.1 --port 8001` и `cd frontend && npm run dev`.
2. Открыть `http://127.0.0.1:3000/dashboard/session?grade=1`, войти только синтетическим профилем и выбрать «Учебный урок» → «Состав числа до 10».
3. Взрослый рядом просит ребёнка самостоятельно начать урок, ответить, запросить подсказку, поставить паузу и вернуться. Не подсказывает до явной трудности.
4. Фиксировать пункты из [PILOT.md](../EXECUTION_PLAN_2026-09-22/PILOT.md#h0): где ребёнок искал кнопку, понял ли подсказку, различил ли её с ответом, что помешало после ошибки и сколько раз вмешался взрослый. Не записывать имена, голос и личные данные.
5. После 1–2 наблюдений создать `docs/audit/pilot-usability-early.md` с фактами и задачами U1b/B2. До этого H0 остаётся OPEN.

## Ограничения и передача

Экран — локальный разработческий вход: нет голоса, авторизации реальных семей, новых уроков и подтверждения удобства ребёнку. JSON-сохранение B2b пока не атомарно между процессами; это S1a. Следующий обязательный ID: **H0** (владелец + педагог); параллельные предметные C0/C1 остаются отдельными READY-карточками.
