# Очередь выполнения

Дата исходного состояния: 22.09.2026. READY — можно брать; WAIT — сначала принять зависимости; DONE — есть доказательство. Статусы ниже не меняются по факту выдачи поручения.

## Ближайший порядок

**По одному исполнителю:** B2a → B2b → U1a → H0 → S1a → S1b → C0 → D2 → B3 → U1b → V1a → V1b → U1c → P1 → R1 → Q1 → Q2 → A1 → R2 → H1.

H0 — раннее наблюдение управления на одном локальном уроке, до расширения интерфейса и голоса; H1 — проверка законченного маршрута с 5–10 семьями. Подготовить форму H0 может Luna уже сейчас. Если участники временно недоступны, технические карточки продолжаются, H0 остаётся OPEN, а найденные впоследствии проблемы возвращаются в U1b/U1c.

C1 можно выполнить в свободный слот GPT-5.5 в любой момент; отсутствие нижнего тома не блокирует пилот на проверенном верхнем. При параллельной работе допустимы B2a/B2b + U1a после фиксации контракта + C0/C1 в отдельных файлах. Рекомендуемый максимум — два исполнителя; скорость не важнее лимитов и согласованного кода.

## После первого работающего пилота — завершить содержание

Расширение начинается после решения H1 «расширять проверенный маршрут». Если ребёнок не может управлять занятием или не получается самостоятельный перенос, сначала исправить соответствующие C0/B3/U1-карточки и повторить проблемные наблюдения. Нет данных H1 — не объявлять продуктовую гипотезу подтверждённой. Поиск источника C1 и исправление уже найденной ошибки содержания не нужно откладывать до пилота.

|---|---|---|---|

| B4 | Sol high, UI при необходимости Terra | Один принятый пакет C3; конкретные lesson_id/version | [SOL.md](SOL.md#b4): явный допуск и весь маршрут, без fallback на чужую тему |

C1 должен быть решён до заявления «1 класс сверен с китайской основой»: отсутствующие источники нельзя закрыть количеством тестов. Если оригинал недоступен, явно выбрать и подтвердить новое издание либо обозначить авторскую тему; прежние страницы не переносить автоматически.

## Что сейчас не заказывать

Повторный аудит всех архивов; массовую перепись 1–9; новый frontend с нуля; новую агентную платформу; поиск идеальной модели среди всей таблицы; платежи и тарифный кабинет; автоматическое расширение уроков по похожим номерам. Для этих работ нет необходимости на ближайшем пути к рабочему занятию.

Стратегический объём 1–9 сохранён. Пилот не означает готовность всех классов и не даёт разнообразной программы на 3 часа ежедневно. Срок завершения определять после первых B2/S1/U1 карточек по реальной скорости и предметной проверке, без обещаний числа недель из подписочных квот.
