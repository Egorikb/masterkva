# Когда считать проект готовым

## M1 — работающий голосовой пилот

Готовность означает не единичный HTTP-ответ, а наблюдаемый маршрут на **явно перечисленном проверенном пакете навыков**. Перед запуском записать список навыков/уроков/версий и источников; всё вне списка недоступно ребёнку.

- Родитель входит, выбирает ребёнка; чужой профиль недоступен. Новый ребёнок не получает выдуманный прогресс.
- Ребёнок видит доступный предмет/блок, получает один вопрос, отвечает текстом или голосом. Может исправить распознавание, запросить подсказку/объяснение, поставить паузу и вернуться.
- Диагностика ведёт к подходящему разрешённому заданию, объяснение связано с ним, самостоятельный перенос проверяется другим вопросом. После ошибок есть понятный выход.
- Сервер проверяет текущую версию и все части. Rubric ждёт взрослого; подсказки и технические ошибки не считаются самостоятельным успехом.
- Повтор/конкуренция HTTP не дублируют попытку; перезапуск сохраняет место; отменённый голосовой запрос не двигает занятие.
- Голос работает на целевых устройствах; при отказе остаётся текст. Ключи — на сервере. Измерены расходы/задержки короткого реального сеанса; задан потолок расходов.
- Родитель видит фактические результаты, помощь и непроверенные умения. Бэкап восстановлен; инструкция запуска воспроизводима.
- Q1 пройден на кандидатном SHA; независимая проверка A1 приняла этот объём; блокирующие дефекты исправлены.
- Педагог проверил пилотные задания, проведено короткое наблюдаемое занятие с ребёнком и внесены выявленные препятствия. Это H1, её не отмечает выполненной модель без наблюдения.

Первый пилот может быть локальным/закрытым. Дата публичного запуска, домен и расходы выбираются отдельно на готовом кандидате. До S1b не заявлять готовность для нескольких семей.

## M2 — завершённый 1 класс

Приняты M1 и все C3/B4-пакеты. Есть матрица всех 26 тем/78 исходных заданий и добавленных вариантов: источник → предметная проверка → оценивание → визуал → runtime → прогресс. Каждая тема проходит настоящий маршрут; наличие JSON не считается подключением. Нижний том подтверждён либо замена/авторская часть явно согласована и проверена. Неподтверждённые источники не замаскированы статусом unit_verified.

Контрольные задания отделены от обучения, повторные занятия не ограничены заучиванием одного ответа. Пособие соответствует текущим версиям. Педагог проверил содержание; пользователь видит честные границы китайской основы и российской адаптации.

## M3 — завершены 1–9 классы

Для каждого класса приняты предметные пакеты C2, их runtime B4 и итог GN. Проверены предпосылки между классами, отрицательные случаи оценивания, рисунки/объяснения и соответствующие визуалы. Наличие прежних 465 структурно размеченных заданий не закрывает эту приёмку. Новые классы не требуют новой системы авторизации, голоса или хранения.

Три часа в день — параметр нагрузки/стоимости, не свидетельство достаточного контента или рекомендация непрерывного занятия. Разнообразие и педагогический режим подтверждаются содержанием и наблюдением.

## Технические команды

Из `ACTIVE` на синтетических данных; применять к изменённым областям. Полный набор — на интеграционных этапах Q1/релизе.

```bash
python3 backend/scripts/validate_adapted_lessons.py
python3 backend/scripts/validate_grade1_topic_identity.py
python3 backend/scripts/validate_grade1_reference.py --verify-sources
PYTHONDONTWRITEBYTECODE=1 timeout 55s python3 -m pytest -q tests -p no:cacheprovider -o faulthandler_timeout=25
git diff --check
```

Из `ACTIVE/frontend`:

```bash
npm run typecheck
npm run lint
npm run build
```

Если набор вырос, обоснованно увеличить timeout вместо исключения медленных тестов. При зависании TestClient учитывать уже найденное ограничение песочницы; честно записывать незавершённый прогон. Браузерные и живые голосовые проверки не заменяются успешной сборкой. Эти команды перечислены как условия будущих карточек; создание плана не запускало новый регрессионный прогон.

## Формат передачи результата

```text
Карточка / модель / дата:
Статус: DONE | PARTIAL | BLOCKED
База и результат: SHA либо точный перечень незакоммиченных файлов
Что теперь работает:
Проверки: команда → результат; браузер/живой API отдельно
Ограничения и незакрытые условия:
Следующая карточка и переданный контракт:
```

DONE требует всех условий конкретной карточки. Недоступный источник, отсутствующая живая проверка и тестовая заглушка должны оставаться видимыми. В WORKLOG — краткая запись со ссылкой; полные доказательства — один соответствующий отчёт в `docs/audit/`.
