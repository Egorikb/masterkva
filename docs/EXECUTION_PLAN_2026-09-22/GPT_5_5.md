# GPT-5.5 — китайская основа и педагогическое содержание

Режим **high**, один небольшой пакет. Независимое предметное чтение — основание выбора этой модели по прежней оркестрации, не утверждение, что она дешевле Terra/Sol. Рутинный экспорт и инвентарь отдавать Luna. Общие правила: [README](README.md).

## C0

**Результат:** содержательно законченный пакет для первого учебного маршрута.

**Вход:** `docs/GRADE1_REFERENCE.md`, `docs/grade1/TEACHER_GUIDE.md`, manifest источников, проверенный верхний китайский том, задания v2.0 и решения D1. Нижний том для C0 не требуется.

**Начальный маршрут:** состав числа → десяток и единицы → сложение через десяток → вычитание через десяток. Сначала проверить, какие его части действительно подтверждены доступным оригиналом и текущими материалами. Неподтверждённую часть выделить как авторскую адаптацию с отдельной проверкой либо ограничить первый пакет; не приписывать её верхнему тому.

**Размер запуска:** один навык; C0/<skill> повторяется для остальных. Сначала переиспользовать принятые задания. На навык подготовить входную пробу, разобранный пример, управляемую практику, самостоятельный перенос и отдельную повторную проверку. Количество вариантов определяется различимыми проверяемыми умениями; не генерировать десятки дублей для объёма.

Для вероятных причин ошибки составить компактную таблицу: наблюдение → гипотеза → различающая проба → соответствующее объяснение → что ещё неизвестно. Например, отделить непонимание дополнения до десятка от трудности текста условия. Описку не объявлять установленной без уточнения; ошибки речи/сети не интерпретировать как математический пробел. Термины в таблице описывают учебное действие, а не личные качества ребёнка.

Задать действия на доске и короткие сопровождающие реплики. Подготовить разные, сопоставимые по умению задачи для входной пробы, проверки после помощи и проверки спустя несколько дней; хотя бы одна контрольная задача использует иную форму того же действия. Контрольные задачи не включать в объяснение. Интервал и правило достаточного самостоятельного результата перед пилотом согласует педагог.

**Запись:** только перечисленные темы/уроки и manifest, предметный отчёт `docs/audit/pilot-content.md`, пособие через существующий экспорт. Сохранять историю версии изменённых контрактов; старую попытку нельзя переоценивать по новому материалу.

**Приёмка каждого пакета:**

- Китайский метод и русская адаптация различимы; раздел/печатная страница подтверждены просмотром источника, а не legacy_page_hint.
- Условие однозначно, ответ/решение математически верны; ученик видит ровно один вопрос или одну явно обозначенную часть.
- Подсказка помогает действию и не выдаёт контрольный ответ. Контрольный вопрос не повторяет уже показанное решение.
- Exact/ordered/rubric выбраны по смыслу; рисунок и объяснение имеют критерии и способ передачи взрослому.
- Для визуальной задачи существует нужная сцена/схема либо честная пометка для Terra; формулировка не ссылается на невидимый рисунок.
- Предпосылки, типичная ошибка и правило самостоятельной проверки записаны. Предметное независимое чтение делает другой исполнитель по конкретному пакету; арифметика дополнительно проверяется кодом.
- По результатам разных уточняющих проб можно выбрать разную помощь; при неопределённости есть нейтральное уточнение. Комплект позволяет проверить перенос и сохранение результата, а не только повтор разобранного примера.
- Китайский источник и место умения в российском обучении описаны отдельно. Непроверенное соответствие российской программе явно отмечено; заменённые имена/валюта не считаются подтверждением такого соответствия.

После C0 Luna делает D2, Sol включает B3. Автор текста не включает его в runtime сам.

## C1

**Результат:** подтверждение китайского учебника второго полугодия для тем 15–26.

**Вход:** `backend/data/curriculum/grade_1_sources.json`, существующие оригиналы и пособие. **Пути:** source manifest, полученный оригинал в `backend/data/knowledge_bases/math_1_class/raw/` по принятой структуре, связанные source-поля; `docs/audit/grade1-lower-source.md`.

Проверить существующие местные файлы до поиска. Затем найти доступный оригинал через первоисточник/издателя. Установить название, издательство, издание, ISBN при наличии, оглавление, SHA-256, соответствие печатных страниц страницам PDF. Просмотреть относящиеся к темам разделы, а не только титул. Различия редакций и авторские расширения указать отдельно.

**Приёмка:** `validate_grade1_reference.py --verify-sources` и предметная таблица просмотренных разделов. Если источник не найден, сохранить проверенные кандидаты и точный пробел; не заполнять страницы догадками. Остановить повторный поиск по тем же источникам: нужен новый источник/файл, а не более дорогой агент. Сам PDF по умолчанию не добавлять в обычный Git-коммит.

## C3

**Результат:** доведённые до предметной приёмки 1–2 темы 1 класса за запуск, после первого работающего пилота.

Повторно не переписывать все 78 заданий. Взять тему из незакрытой матрицы G1, проверить её источник, решение, parts/rubric, подсказки, визуал, предпосылки и самостоятельный перенос. Исправлять только обнаруженные дефекты; при изменении оцениваемого содержания фиксировать новую версию. Нижние темы требуют C1 или явно принятой альтернативы источника.

**Приёмка:** условия C0 плюс отрицательные примеры оценки, запись причин изменения, независимое чтение и валидаторы. После приёмки передать конкретные ID/version в B4. «Текст идеален» без источника/прогона не статус.

## C2

**Результат:** тот же стандарт для 2, затем 3, затем отдельно 4–9 классов.

За запуск 1–2 связанные темы одного класса; Luna до этого делает их инвентарь. Для выбранного класса сначала определить реальный исходник и способы оценивания, затем пример, задачи, решения по частям, рубрики и возрастные формулировки. Старые механические отметки готовности не принимать за предметную экспертизу. Не переносить автоматически границы российской программы из китайского учебника.

Каждый пакет проходит C0-подобную приёмку, затем B4. Итог класса — GN. Сверка педагогом и опыт ребёнка остаются отдельными условиями; модель их не заменяет.
