# Внешний тариф — необязательная помощь

Названия ниже сохранены **из списка пользователя**. Их точные API ID, доступность, ограничения и цены этим планом не подтверждены. Таблица задаёт возможное поручение при наличии доступа, а не рейтинг моделей. Основная очередь полностью исполнима без этого тарифа и без Notion-агентов.

Для экономии выбирать одного помощника на один тип работы; первый маленький результат проверить до передачи следующего пакета. Не отправлять всем одну и ту же задачу и не превращать подготовку в длительный бенчмарк. Через Notion модель должна иметь реально доступный инструмент запуска и чтения результата; доступ к страницам этого не доказывает.

## Шаблоны вспомогательных ТЗ

| Код | Точный вход и результат | Кто принимает |
|---|---|---|
| E1 | Один предоставленный китайский раздел: черновой перевод, неизменные числа, номера задач и страницы; неразборчивое обозначить | GPT-5.5 сверяет оригинал |
| E2 | До 5 предоставленных «условие + решение»: найти математическое противоречие, показать расчёт/контрпример, без переписывания корпуса | Предметный исполнитель + арифметическая проверка |
| E3 | До 10 принятых задач: короткая русская подсказка без итогового ответа и новых чисел | Владелец C0/C3/C2 |
| E4 | Один небольшой diff и воспроизведение дефекта: предложить минимальный исправляющий фрагмент или полезную регрессию | Sol/Terra читает и запускает |
| E5 | Готовый обезличенный список замечаний: убрать дубли и вернуть ID → категория → приоритет, не выдумывать факты | Luna сверяет с исходным списком |

## Готовое поручение помощнику

```text
Выполни только E2: проверь приложенные 5 пар «условие — решение».
Для каждой верни ID, есть ли ошибка, точный расчёт или контрпример.
Если данных недостаточно, напиши что отсутствует. Не меняй числа, не
переписывай остальные задачи и не делай вывод о готовности всего класса.
Материал — обезличенный черновик для последующей предметной проверки.
```

Внешнему помощнику передавать только нужный учебный фрагмент или очищенный diff. Не нужны весь репозиторий, ключи, состояния детей и история их разговоров. Его ответ не попадает в детский материал автоматически.

Преподаватель в приложении — отдельный выбор V1a: доступность модели в чате/подписке не доказывает наличие API и право автоматизированного использования. Рабочую модель для разработки не нужно одновременно выбирать преподавателем.
