# 1 класс — эталон содержания и границы готовности

Версия **2.0**, работа 2026-09-09–10. Подготовлены **26 тем, 26 разобранных примеров и 78 заданий**. Это стандарт структуры и редакторской проработки для остальных классов. Полнота годового обучения, удобство для ребёнка и автономная работа приложения ещё не подтверждены.

Для чтения без JSON: [пособие преподавателя](grade1/TEACHER_GUIDE.md). Источник истины: [задания](../backend/data/lessons/grade_1_ru_adapted.json), [учебный план](../backend/data/curriculum/grade_1_full.json), [реестр китайских источников](../backend/data/curriculum/grade_1_sources.json).

## Содержательные исправления

- У каждого задания заново сформулированы условие, подсказка, решение и заметка взрослому. У темы есть цель, предварительные темы, пример и типичная ошибка. Предварительные темы образуют граф без циклов.
- Введён ноль и состав числа с нулём. Устранены подсказки ответа внутри следующего вопроса.
- Тема 5 первого полугодия возвращена к объёмным телам китайского оригинала. Шар, куб и цилиндр рассматриваются в заданиях, прямоугольный параллелепипед — в примере. Плоские фигуры отдельно в теме 15; отпечаток грани служит переходом между ними.
- Тема 13 — сложение в пределах 20, а не сложение двух двузначных чисел. Тема 17 — закрепление вычитания в пределах 20; её нижний источник ещё требует сверки.
- В часах оставлены целые часы. Удалены неверное положение стрелок для 5:30 и ненужный перевод в 24-часовой формат. Начало занятий не имеет универсального ответа «утром».
- В теме без перехода исправлено `60−18` на `68−18`. Денежные истории до изучения заимствования не требуют его скрытно; цены обозначены как учебные.
- Рисунок нельзя оценить строкой «4 фигуры». У классификации задан признак, у последовательности — правило. Пересчёт предметов, рисунок и объяснение имеют наблюдаемые критерии.
- Старые расплывчатые поля решений и неподтверждённые указания на сцену удалены. Предметы перечислены явно; отсутствующая картинка не скрыта фразой «посмотри на рисунок».
- Для числовых ответов 0–100 добавлены словесные формы. Это ограниченные разрешённые варианты, не готовое понимание произвольного голосового ответа.

Сохранён китайский подход: действие с предметами, представление, запись и объяснение способа. Это не означает совпадение с российским годовым курсом. В [федеральной программе математики 1–4 классов, редакция 2025](https://edsoo.ru/wp-content/uploads/2025/07/2025_noo_frp_matematika_1-4.pdf) первый класс работает с числами до 20 и включает измерение, отрезки и простые таблицы. Поэтому числа и действия до 100 здесь выделены как расширение. Для полного российского покрытия ещё нужен отдельный блок см/дм, измерения и построения отрезков, таблиц и явных заданий на истинность утверждений. Это сопоставление охвата, не сертификация соответствия программе.

## Контракт для следующих классов

| Поле | Назначение |
|---|---|
| `lesson_id`, `content_version` | Стабильное имя и версия; не идентификатор диагностики |
| `student_prompt`, `task` | Одно и то же условие для ребёнка |
| `presentation.prompts` | Части в порядке предъявления; пока инструкция для будущего UI |
| `assessment.kind: exact` | Один вопрос; альтернативы только внутри его `expected` |
| `assessment.kind: ordered` | Несколько вопросов; отдельный ответ на каждый; обязательны все части |
| `assessment.kind: rubric` | Наблюдаемые критерии, без автоматического зачёта |
| `expected_answers` | Первые эталоны по порядку для совместимости; запрещено трактовать как OR для всего задания |
| `solution_steps`, `hint`, `teacher_note` | Решение, отдельная подсказка, заметка взрослому; не детские поля API |
| `lesson_skills` | Узкий предметный смысл; пока названия, не runtime skill_id |
| `source`, `review` | Источник и статус проверки; независимый педагог остаётся pending |
| `topic.teaching` | Цель, пример, ошибка, предварительные темы и порядок проведения |

Состав: **24 exact + 33 ordered + 21 rubric**, **111 проверяемых частей**, из них **79 с арифметическим выражением** для машинного пересчёта. Остальные точные ответы, рубрики и 26 примеров прочитаны отдельно. Числовая проверка сама по себе не подтверждает смысл условия.

Чистая функция `assess_lesson` в `backend/deeptutor/services/lesson_assessment.py` возвращает `correct`, `incorrect`, `needs_review` или `invalid_input` и не записывает прогресс. Ordered принимает список строк либо строку с разделителем `;`; запятая остаётся десятичным разделителем. Рисунки и объяснения требуют наблюдения. Если урок просит и число, и объяснение, одно число может быть недостаточно, поэтому такой урок допустимо целиком оставить rubric.

## Проверки и воспроизведение

```bash
python3 backend/scripts/validate_adapted_lessons.py
python3 backend/scripts/validate_grade1_reference.py --verify-sources
pytest -q tests/services/test_lesson_assessment.py tests/services/test_grade1_reference.py
python3 backend/scripts/export_grade1_guide.py
git diff --check
```

Gate проверяет 26 тем и 78 уникальных lesson_id, источники, индексы, предъявляемый текст, критерии, примеры и предварительные темы. Арифметика пересчитывается через ограниченный AST и Fraction без `eval`. Отрицательные тесты портят ответ, источник, вопрос, идентификатор и число частей. Рисунок и свободное объяснение gate не оценивает.

Обычный запуск возможен без сырых PDF в Git-копии. `--verify-sources` сверяет локальные оригиналы с hash; известное отсутствие нижнего тома выводится отдельно. Успех проверки не означает, что оба тома найдены.

Прежние `enrich_adapted_lessons.py` и `complete_primary_lessons.py` пропускают корпус с `reference_version`, чтобы не затереть ручную редактуру или не присвоить рисунку exact из-за пустого expected_answers. Пособие генерируется из JSON; вручную его не править.

## Оставшиеся границы

1. `practice_engine.py` выбирает задания из своей базы/диагностики. Новый assessor ещё не подключён к реальным попыткам. Подготовленный материал не равен работающему маршруту приложения.
2. RAG собирает материал по темам, а краткая сводка для LLM теряет структуру. Эталон нужно выбирать по lesson_id, не восстанавливать из случайного фрагмента.
3. UI ещё не исполняет новый presentation. Общая карта визуалов согласована по названиям/навыкам, но это не проверка конкретной сцены, особенно объёмных тел.
4. Трёх заданий на тему недостаточно для доказательства устойчивого освоения и полного покрытия учебника. Банк вариантов и повторение во времени требуют отдельной предметной работы и наблюдения занятий.
5. Нужны нижний оригинал, проверка педагогом и наблюдение ребёнка. Статус: `reviewed_reference_candidate`, без обещания «идеальный курс» или «100% готовность».
