## Действующие решения

1. Развивать `ACTIVE`, а не объединять все копии DeepTutor.
2. Backend проверяет ответы, прогресс и переходы; LLM формулирует объяснение.
3. Первый маршрут: состав числа → десятки и единицы → сложение/вычитание через десяток → равные группы → умножение и деление.
4. Для ребёнка использовать короткое занятие с одной задачей, крупными действиями, подсказкой, переформулировкой и паузой.
5. Долговременная память проекта ведётся здесь и кратко дублируется в `MEMORY.md`.
