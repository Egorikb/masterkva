**Запись:** новый `docs/audit/grade1-topic-identity.md` и кандидат `backend/data/curriculum/lesson_runtime_map.json`.

**Сделать:** для 26 тем сопоставить canonical_topic_id, lesson_id, диагностический topic_id, skill_id, item_family и content_version. Доказывать соответствие содержанием. Числовая тема 3, `g1-t03-l01` и runtime `g1_t03` не равны по умолчанию. Неоднозначное отметить review_required, отсутствующее — unmapped.

**Приёмка:** все 78 lesson_id учтены ровно один раз; ссылки существуют; выдуманных skill_id нет; спорные строки вынесены отдельно. Sol подтверждает строки для B1. Можно начинать сейчас, не менять существующие уроки или состояния.

## C1 — GPT-5.5: подтвердить китайский источник второго полугодия

**Вход:** `backend/data/curriculum/grade_1_sources.json`, оригинал верхнего тома и пособие.

**Запись:** полученный оригинал в `backend/data/knowledge_bases/math_1_class/raw/`, manifest, связанные поля curriculum/lessons и раздел источников GRADE1_REFERENCE.

**Сделать:** найти доступный нижний том PEP, сверить титул, издательство, издание, ISBN, оглавление и разделы. Записать hash и соответствие печатной страницы PDF. Для тем 15–26 установить раздел-основу либо пометить авторское расширение. Особое внимание порядку тем 20–24 и границам 25–26. Не подставлять другое издание под старые страницы.

**Приёмка:** `python3 backend/scripts/validate_grade1_reference.py --verify-sources` и список фактически просмотренных разделов/расхождений. При недоступности оригинала остаётся unverified; legacy_page_hint не является доказательством. Независима от D1.

## B1 — Sol: подключить эталонное задание к реальному маршруту

**Вход:** подтверждённые строки D1 и контракт версии 2.0.

**Запись:** `backend/deeptutor/services/practice_engine.py`, небольшой загрузчик рядом при необходимости, `api/routers/plugins_api.py`, затронутые API-модели и тесты.

**Сделать:** выбирать конкретный lesson_id + content_version; выдавать только детские поля текущей части. Ordered предъявлять последовательно и завершать после всех частей. Rubric оставлять needs_review с объяснением/наблюдением взрослого; произвольная реплика не повышает mastery. Передать Terra стабильный API-контракт. Решения, эталоны и teacher_note не должны попадать в детский API-ответ.

**Приёмка:** интеграционный сценарий использует настоящий урок JSON; изменение эталона в тестовой копии меняет оценку. Один ответ не закрывает несколько вопросов; expected_answers не применяется как OR для всего урока; неизвестный lesson_id отвергается; случайный фрагмент RAG не выбирает упражнение.

**Зависимость:** D1. Сначала одна проверенная арифметическая цепочка первого полугодия, затем остальные подтверждённые строки.

## B2 — Sol: действия, повтор запроса и выход из remediation

**Запись:** `practice_engine.py`, `remediation_engine.py`, `diagnostic_engine.py`, `plugins_api.py` и тесты.

**Сделать:** разделить answer / hint / rephrase / pause, добавить идентификатор попытки, завершить переход после повторных ошибок. Сохранить числовые исправления `83e53b8`.

**Приёмка:** подсказка не является математической ошибкой; повтор HTTP не создаёт вторую попытку; после трёх неверных ответов есть понятный следующий шаг; дроби и единицы сохраняют смысл. Регрессии воспроизводят исправленные дефекты.

**Зависимость:** B1; после B2 общие API-файлы можно передать Terra для S1.

## S1 — Terra: отдельные профили и сохранение попыток

**Запись:** `student_profile_store.py`, модуль хранения при необходимости, миграция, тесты и переданный после B2 API.

**Сделать:** серверная идентичность ребёнка, версия урока в попытке, транзакционный переход, pause/resume и идемпотентность. Если текущий JSON этого не обеспечивает, использовать встроенную SQLite. Сначала миграция синтетических данных.

**Приёмка:** два ребёнка не смешиваются; перезапуск не теряет часть задания; повтор запроса не удваивает запись; старая попытка не оценивается по новому эталону. Существующий `user_states.json` не переписывать в рамках разработки; перенос реальных данных — отдельный конкретный этап после проверки миграции.

## U1 — Terra: удобный экран ребёнка

**Запись:** `frontend/` и UI-сценарии; backend читать по контракту B1.

**Сделать:** один вопрос за раз; крупные «Ответить», «Подсказка», «Повтори», «Пауза»; текстовый ввод рядом с голосом; остановка/повтор озвучки. Показывать список предметов до задания. Отсутствующую сцену не заменять случайной картинкой. Для тел показывать объём, для рисунка — понятную передачу взрослому. Персонаж не закрывает рабочую область.

## V1 — Sol: голосовой преподаватель и измерение расходов

**Запись:** `teacher_llm.py`, `learning_rag.py`, backend-адаптеры STT/TTS, конфигурация без ключей и тесты.

**Сделать:** модель объясняет текущий шаг; оценку и переход определяет сервер. Неоднозначное распознавание сначала подтверждается. Добавить отмену, timeout, fallback и счётчики токенов, секунд STT, единиц тарификации TTS и повторов.

**Выбор преподавателя:** сравнить доступные через реальный API Qwen Flash/Plus и DeepSeek Flash как кандидатов на одной обезличенной выборке. Точные названия, условия применения и цену проверить у выбранного провайдера на дату подключения. Codex используется для разработки; подписка не является бесплатным API приложения.

**Приёмка:** ошибка STT не считается ошибкой по математике; озвучка останавливается; после отмены нет запоздалого следующего шага; при отказе модели остаётся понятная реплика. Смету на 21 час занятий в неделю считать по измеренной доле речи и токенам. Исторические 700 ₽/неделю не выдавать за подтверждённую цену готового продукта.

**Зависимость:** B1/B2 и договорённость с U1; платные вызовы после локальных тестов и настройки реального провайдера.

## C2 — GPT-5.5 и Luna: следующие классы

**GPT-5.5:** 2 класс, затем 3, потом отдельные пакеты 4–9. Сверить смысл с оригиналом, подготовить примеры, решения, критерии рисунков/объяснений и ответы по частям.

**Luna:** инвентарь, поиск дублей, экспорт пособий, структурные проверки. Изменять только согласованный пакет. Прежние миграции пропускают reference_version — не обходить эту защиту.

**Приёмка:** источник каждого раздела имеет честный статус; все задания имеют решение/рубрику; есть отрицательные проверки и независимое предметное чтение. Зелёный старый gate 2–9 доказывает только структуру. Инвентарь можно делать параллельно backend; предметную редактуру одного файла — последовательно.

**Проверить:** совпадение темы материала и runtime, раскрытие ответов, все части оценки, rubric без автоматического mastery, выход из remediation, профили, повторы, перезапуск, сцены, задержки и стоимость голоса.
