# MasterKva

Monorepo for the MasterKva project.

## Structure
- `frontend/` — Next.js frontend from `front_deeptutor`
- `backend/` — Python DeepTutor backend/core from `deeptutor_analyzed`

## Notes
- Secrets, caches, build artifacts, and local env files are intentionally excluded.
- This repo is intended to keep the active frontend/backend split in one place.
